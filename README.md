# Wanderlust — Travel Beyond Borders
<img width="1817" height="1032" alt="image" src="https://github.com/user-attachments/assets/e4b53004-af2f-4bcf-a147-b5dfe2213b9d" />


A modern, responsive travel discovery landing page crafted with semantic HTML5 and vanilla CSS3.

## Features

- **Hero Section**: Immersive background and call-to-actions.
- **Curated Destinations**: Interactive cards highlighting travel hotspots.
- **Unique Experiences**: Grid of travel styles and tailored packages.
- **Stories & Testimonials**: Social proof from travelers.
- **Newsletter & Contact**: Clean forms for customer engagement.
- **Responsive Design**: Optimized for desktops, tablets, and mobile screens.

## Tech Stack

- **HTML5**: Semantic tags and accessibility landmarks.
- **CSS3**: Modern layouts with Flexbox and CSS Grid, smooth transitions, custom properties.
- **Google Fonts**: Outfit & DM Serif Display.

## Getting Started

Open `index.html` in your browser or serve it using any local web server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js (npx)
npx serve
```
